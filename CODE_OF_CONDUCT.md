# Codigo de Conduta do Prompt Arena

## Nossos princípios

Este projeto busca um ambiente respeitoso, inclusivo e profissional para todos os colaboradores, independentemente de:

- Identidade de genero, orientacao sexual
- Raça, etnia, nacionalidade
- Religiao ou crenca
- Idade, aparência, capacidade
- Nivel de experiencia ou posicao

## Comportamento esperado

- Use linguagem acolhedora
- Respeite opinioes diferentes
- Aceite feedback construtivo
- Foque no que e melhor para a comunidade

## Comportamento inaceitável

- Assédio, discriminacao ou ofensas
- Comentarios sexistas ou racistas
- Intimidacao ou perseguicao
- Divulgacao de dados privados sem consentimento

Aplicacao: mantenedores podem banir colaboradores que violarem este codigo.
